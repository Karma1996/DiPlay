2. 实现摘要与范围对照

自动连接收敛为一条链路：四类触发源 → 纯策略门禁 AutoConnectGate → 唯一状态机 AutoConnectSession（内含 AutoConnectBudget）→ 既有 DiPlayActivity.connect(true) / CarPlay 栈。手动与 USB 路径不改语义，自动路径不弹阻塞框。

7. 部署、开关、回滚与故障处理

  • 无服务端部署；车机端 APK 增量升级。版本号、CHANGELOG、源码 ZIP 由人类发布流程负责（约章 §9.4）。
  • 紧急降级开关：AutoConnectPreferences.AUTO_CONNECT_DEFAULT_ON（构建期常量，默认 true）。置 false 后首次成功不再自动开启总开关，其余不变。
  • 自动连接失败闭合：终态 FAILED / NEEDS_CHOICE / BLOCKED / CANCELLED；Home inline notice 显示原因与进度；不弹阻塞对话框。
  • 关闭总开关即撤销：取消进行中的自动会话、注销唤醒接收器、四个触发全部 Ignore(OFF)。
